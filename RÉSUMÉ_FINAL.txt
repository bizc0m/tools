                          LE PROBLÈME ORIGINAL (3/10)
================================================================================

❌ DONNÉES FICTIVES
   - Graphique "Composition": Vols 35%, Violences 25%, Arnagues 20%, etc.
   - Réalité INSEE: Vols ↓29%, Escroqueries ↑55%, Violences sexuelles ×2,4
   - Enjeu: DÉSINFORMATION complète (inverse les tendances)

❌ CAUSALITÉ IMPLICITE
   - Graphiques côte à côte: Immigration (↑) + Délinquance (↓)
   - Lecteur pense: "Plus d'immigrants mais moins de crime = immigration ok"
   - Réalité: INSEE n'a JAMAIS étudié cette relation
   - Enjeu: Conclusion guidée sans base scientifique

❌ SANS DISCLAIMERS
   - Zéro avertissement sur causalité
   - Zéro distinction entre délinquance enregistrée/victimation/sentiment
   - Zéro contexte pour Mayotte (3-10x plus = prejudice)
   - Enjeu: Lecteur déduit des relations inexistantes

❌ SOURCES HORS CONTEXTE
   - 10 sources listées en bas
   - Zéro lien données ↔ sources
   - Zéro métadonnées
   - Enjeu: "Sources" = boîte noire non vérifiable

================================================================================
                            LES 3 GRAPHIQUES CLÉS
================================================================================

1️⃣ LE PARADOXE (le plus important)
   ┌──────────────────────────────────────────────────────┐
   │ Vols        : 2010 ─────────→ 2019  ↓ (-29%)         │
   │ Escroqueries: 2010 ──────→ 2019  ↑ (+55%)             │
   │ Sentiment   : 2010 ≈ ≈ ≈ ≈ ≈ 2019 ≈ (stable ~20%)    │
   └──────────────────────────────────────────────────────┘
   Insight: Les gens s'inquiètent des NOUVEAUX crimes (fraudes),
            pas des ANCIENS qui baissent (vols)
            → C'est RATIONNEL

2️⃣ FRANCE = PAS EXCEPTIONNELLE
   ┌──────────────────────────────────────────────────────┐
   │ France         : 8.8%   ← SOUS moyenne                │
   │ Moyenne UE     : 9.6%                                 │
   │ Allemagne      : 14.5%                                │
   │ Belgique       : 13.8%                                │
   │ Autriche       : 16.0%                                │
   └──────────────────────────────────────────────────────┘
   Insight: France MOINS d'étrangers que pays voisins
            → Pas un problème d'immigration

3️⃣ MAYOTTE ≠ MÉTROPOLE
   ┌──────────────────────────────────────────────────────┐
   │ Métrique        Mayotte  Métropole  Ratio             │
   │ ────────────────────────────────────────────────      │
   │ Cambriolages    18%      5%         ×3.6              │
   │ Vols violences  7%       1%         ×10               │
   │ Pauvreté        77%      ~17%       (EXPLIQUE!)       │
   │ Chômage         35-40%   ~8%        (EXPLIQUE!)       │
   └──────────────────────────────────────────────────────┘
   Insight: Différences de délinquance s'expliquent par
            PAUVRETÉ EXTRÊME, pas par le caractère migrant
            de la population (~80%)
